# Reela Create

Run `reela create -h` for the current option list and defaults.

## Basic use

Preview a video before submitting it:

```bash
reela create "A 30-second product demo" \
  --session "Spring product launch" \
  --visual ai-video \
  --duration 30 \
  --layout portrait \
  --dry-run
```

After reviewing the preview, run the same command without `--dry-run` to create the video.

## Visual options

Repeat `--visual` when using more than one visual option. Do not join values with commas.

| Goal | Options |
| --- | --- |
| AI-generated video | `--visual ai-video` |
| Avatar video | `--visual avatar --visual ai-video --avatar <id>` |
| Edit clips without their original audio | `--visual original-clip --file video-source:<path>` |
| Edit clips and keep their original audio | `--visual original-sync --file video-audio:<path>` |
| Animate one image | `--visual image-video --file original-image:<path>` |
| Match an image's style | `--visual ai-video --file reference-image:<path>` |
| Add AI-generated shots to clips | Add `--visual ai-video` to the clip options |

Example with multiple visual options:

```bash
reela create "Product demo with presenter and product shots" \
  --session "Product demo" \
  --visual avatar \
  --visual original-clip \
  --visual ai-video \
  --avatar <id> \
  --file video-source:./product-demo.mp4 \
  --dry-run
```

## Music videos

For a song generated by Reela, use `--music-video`:

```bash
reela create "City-pop song and music video about a rainy neon street" \
  --session "Rainy neon city-pop MV" \
  --visual ai-video \
  --music-video \
  --duration 60 \
  --dry-run
```

For your own song, attach the song instead. Do not add `--music-video`:

```bash
reela create "City-pop MV with neon visuals" \
  --session "City-pop neon MV" \
  --visual ai-video \
  --file background-music:./song-with-lyrics.mp3 \
  --duration 180 \
  --layout portrait \
  --dry-run
```

## Sessions

Use `--session` with a short, descriptive project title. Reuse the same title for related videos.

```bash
--session "Spring product launch TikTok videos"
```

## Duration, layout, and quality

```bash
--duration 30
--layout landscape   # or portrait, square
--tier <tier>
```

List currently available quality and cost options before choosing a tier:

```bash
reela tiers list
```
