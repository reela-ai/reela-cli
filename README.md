# Reela CLI

Create AI-powered videos from the terminal with [Reela](https://reela.com).

## Quick start

Send the following instruction to your agent:

```
Help me make video on the reela. Read get.reela.com/cli/install.txt and follow every step.
```

## Install

Linux / macOS:

```sh
curl -fsSL https://get.reela.com/reela-cli/install.sh | bash
```

Run `reela update` to get the latest version.
